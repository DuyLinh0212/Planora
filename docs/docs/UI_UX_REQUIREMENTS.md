# UI / UX REQUIREMENTS

## Platforms
- User Web.
- Mobile.
- Admin Web.

## Themes
1. Light.
2. Dark.
3. Calm: tone yên bình, xanh là màu chủ đạo.

## Project Navigation
```text
Overview
Plan / Sprints
Tasks
Files
Members
Analytics
Settings
```

## Context Help `?`
Chức năng dễ gây khó hiểu phải có icon `?`, ví dụ:
- Sprint là gì?
- Task Submission là gì?
- Member extension vs Leader extension.
- RBAC.
- Folder Permission.
- Performance Score.

Web có popover/modal; Mobile không phụ thuộc hover.

## Task Detail
Hiện rõ:
- Assignee.
- Status.
- Priority.
- Original/Effective Deadline.
- Extension history.
- Acceptance Criteria.
- Submission.
- Review feedback.

## Storage
- Tree/Breadcrumb.
- Owner.
- Last edited by.
- Version history.
- Permission indicator.
- Search/filter.

## Branding
Cần:
- Mobile App Icon.
- Horizontal Web Logo.
- Favicon.
- Light/Dark logo variant nếu cần.

## Accessibility
- Contrast.
- Keyboard Web.
- Không dùng màu là tín hiệu duy nhất.
- Icon có label.
- Responsive.
