# Planora Web.User masterboard prompt

Mode: built-in `image_gen`

Use case: `ui-mockup`

Create one extremely polished, high-fidelity landscape UI/UX presentation board showing a coherent family of shippable desktop SaaS screens for Planora, a calm project-management cockpit for students, freelancers, and small teams.

Center a large Project Overview for “Campus Launch” with a persistent Night Ink navigation rail and a continuous workstream ribbon connecting Sprint goal → Active work → Review → Done. Surround it with Sign in/Register, My Projects, Sprint Planner/Backlog, Tasks Kanban, Task Detail, Submission/Review, Files, Members & Roles, Analytics, Notifications, Project Settings, Profile & Subscription, Payment Methods, Payment History, responsive tablet/mobile adaptations, and Light/Dark/Calm Blue theme variants.

Render these navigation labels clearly: “Overview”, “Plan / Sprints”, “Tasks”, “Files”, “Members”, “Analytics”, “Settings”. Render “Planora” once. Add small “?” context-help buttons beside Sprint, Submission, Extension, RBAC, Folder permission, and Performance score.

Use Porcelain `#F5F7FB`, Night Ink `#121A2D`, Draft Blue `#3155C6`, Quiet Mist `#DDE8FF`, Lagoon `#36A6A0`, and Signal Coral `#F47B6B`. Use an Instrument Serif impression only for restrained display moments, Manrope-like interface text, and IBM Plex Mono-like dates/metrics. Favor an asymmetric calm project canvas, crisp 8px rhythm, fine dividers, accessible contrast, explicit status text, 8–12px corners, restrained shadows, practical density, generous whitespace, and subtle paper-and-ink character. The structurally useful workstream ribbon is the single memorable design risk.

No people, device photography, 3D scene, perspective distortion, watermark, Angular branding, glassmorphism, neon gradients, excessive pills, floating blobs, generic four-stat-card hero, clipped frames, or unreadable filler paragraphs. Prioritize coherent hierarchy, realistic product UI, and readable labels.
