# Planora Web.Admin masterboard prompt

Mode: built-in `image_gen`

Use case: `ui-mockup`

The two Planora Web.User boards were used only as visual-family references for palette, typography, spacing, navigation rail, browser frames, and presentation quality. They were not edit targets, and their private project/task/file content was not copied.

Create one polished, high-fidelity landscape UI/UX presentation board showing the complete shippable Planora Web.Admin experience. Treat it as an exception-first operations control room for a System Administrator managing accounts, plans, payments, feedback, aggregate analytics, and admin activity.

The dominant “Operations Overview” screen has a Night Ink navigation rail, operational horizon, aggregate user/project/subscription/payment/storage metrics, real charts, a Needs attention queue, recent admin activity, and the exact trust-boundary message: “Aggregate metadata only · Private project content is inaccessible”.

Surround it with: Admin Sign in with two-step verification; Accounts; Account details; Plans; Plan editor; Payments; Payment details with Transaction created → Provider callback → Signature verified → Idempotency checked → Subscription activated; Feedback; Feedback details; aggregate Analytics; Admin activity; Settings & Themes; and a responsive tablet Overview.

Render navigation labels clearly: “Overview”, “Accounts”, “Plans”, “Payments”, “Feedback”, “Analytics”, “Admin Activity”, “Settings”. Render “Planora Admin” once as the primary wordmark.

Use Porcelain `#F5F7FB`, Night Ink `#121A2D`, Draft Blue `#3155C6`, Quiet Mist `#DDE8FF`, Lagoon `#36A6A0`, Signal Coral `#F47B6B`, and Control Amber `#E7A849` only for pending states. Use restrained Instrument Serif for the wordmark or one heading, Manrope-like interface text, and IBM Plex Mono-like dates, IDs, amounts, quotas, and timestamps. Use a strict 8px rhythm, compact tables, fine dividers, accessible contrast, labeled icons, 6–10px corners, restrained shadows, and calm paper-and-ink precision.

The signature element is a useful Trust Boundary band separating aggregate operational metadata from inaccessible private project content. Do not show or provide access to private Project names, Task titles, Folder names, Document content, File previews, member performance, or project-specific analytics. Do not allow editing user Projects, Tasks, or Files. No people, device photography, 3D scene, perspective distortion, watermark, Angular branding, glassmorphism, neon gradients, excessive pills, floating blobs, generic four-stat-card-only dashboard, clipped screens, or illegible pseudo-text.
